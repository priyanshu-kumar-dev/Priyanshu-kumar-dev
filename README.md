### Full Stack E-Commerce & Local Services Platform

**ApnaBazar** is a full-stack web application inspired by modern e-commerce platforms, combined with local service functionality.

The project demonstrates real-world full-stack development including authentication, REST APIs, database management, payment integration, image management and production deployment.

### ✨ Key Features

* 🔐 OTP-based user authentication
* 🔑 JWT authentication
* 🛒 Shopping cart
* ❤️ Wishlist
* 🔍 Product search
* 📦 Order management
* 📍 Address management
* 💳 Razorpay payment integration
* 📱 OTP verification using 2Factor
* ☁️ Cloudinary image management
* 📱 Responsive design
* 🔌 REST API architecture
* 🌐 Production deployment
